📌 Repository Description (English)

Predict the Introverts from the Extroverts is a machine learning project aimed at classifying individuals as introverts or extroverts based on given data features.

The project includes:

📊 Data preprocessing and exploratory data analysis

🤖 Training and evaluating machine learning models

📈 Generating predictions and results

📁 Competition-style datasets (train / test / submission files)

The project is implemented using Python and Jupyter Notebook, making it suitable for both learning purposes and ML competition-style workflows (e.g., Kaggle).
